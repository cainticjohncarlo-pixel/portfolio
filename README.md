# John Carlo Caintic · Portfolio

Live: **https://johncalo.dev**

Personal portfolio for my work as an AI Automation System Builder and Full Stack AI Developer: AI agents, workflow automation, CRM builds, websites and funnels, and Claude Code engineering builds.

## What is inside

- `index.html` · the single-page site (React 18 via Babel standalone, no build step): services, sample works, process, tools, testimonials, blog, contact
- `projects/` · one page per sample work category with video walkthroughs, screenshots, and live builds
  - `ai-automations.html`, `chat-agents.html`, `voice-agents.html`, `websites-funnels.html`, `claude-code.html`
  - `chat-agents.html` and `voice-agents.html` embed live GoHighLevel chat and call widgets so visitors can test a real agent
- `blog/` · three articles on AI lead qualification, connected AI tool stacks, and after-hours lead loss
- `book.html` · booking page
